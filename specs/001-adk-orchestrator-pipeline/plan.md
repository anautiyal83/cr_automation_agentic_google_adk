# Implementation Plan: Google ADK Orchestrator Pipeline

**Branch**: `001-adk-orchestrator-pipeline` | **Date**: 2026-10-16 | **Spec**: [spec.md](spec.md)

## Summary

Rewrite the CR Automation pipeline orchestration using Google ADK with a custom `PipelineAgent(BaseAgent)` that supports conditional backtracking for retry loops. BaseAgent wrappers call existing agents for all 10 steps. 3 LlmAgent peer reviewers analyze failures. NiceGUI UI ported from cr_automation-agentic with optimizations.

## Technical Context

**Language/Version**: Python 3.11+ (agentic layer), Java 8 (JAR modules)

**Primary Dependencies**: google-adk 2.11.0, litellm, nicegui 2.0+, ruamel.yaml, pydantic 2.0+, openpyxl, xlsxwriter, aiosqlite

**Storage**: SQLite (pipeline.db) + file system (data/runs/)

**Testing**: pytest (unit + integration)

**Target Platform**: Windows/Linux server, browser UI at localhost:8000

**Project Type**: Web service (NiceGUI) + agent pipeline

**Performance Goals**: Full pipeline <10 min, milestone display <2s, 70%+ self-correction rate

**Constraints**: Must import existing agents from cr_automation-agentic without src package conflicts; must use ADK BaseAgent API

### Phase 2: Custom PipelineAgent (Critical Path)
Replace SequentialAgent with backtracking-capable orchestrator.

| File | Action |
|------|--------|
| `src/orchestrator/pipeline_agent.py` | New — custom BaseAgent with state-machine loop |

Key design: 23 agents indexed 0-22, with `_step_to_index` mapping step numbers to indices. On each iteration: execute agent, check `_retry_target` in state, jump if set, else advance. Reviewers and routers are conditional (skip if preceding step passed).

### Phase 3: Runner with DB Persistence
Rewrite runner to persist state and emit events.

| File | Action |
|------|--------|
| `src/orchestrator/runner.py` | Rewrite — add DB, EventBus, asyncio.Event milestones |

Key changes: PipelineRunner wraps PipelineAgent execution, monitors state changes, persists StepResult rows, publishes PipelineEvent to EventBus, handles milestone responses via asyncio.Event (not polling).
