# YAML Schema Reference

The authoritative schema files are at `schemas/*.yaml` in the project root.
These companion docs provide OKF-compatible discovery and summaries.

- validation-rules-schema — CIQ validation rules
- json-output-schema — CIQ JSON output template
- workflow-schema — Execution workflow
- simulator-config-schema — MockWire simulator configuration
